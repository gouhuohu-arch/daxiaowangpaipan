# 大小王 · 紫微斗数排盘

纯前端静态网页，排盘全部在浏览器本地完成，**不需要服务器、不需要 API Key、不上传任何数据**。

预览：打开 `index.html` 即可。

---

## 两种产物

| 文件 | 用途 |
|---|---|
| `index.html` + `style.css` + `app.js` | 常规版，三个文件放一起，可直接传静态托管 |
| `ziwei-single.html` | **单文件版（954 KB）**，CSS/JS 全内联，发微信/邮件/存本地都能直接打开 |

两个版本内容完全一致，二选一即可。

- 手机端：12 宫自动缩放为 4×4 完整网格，不横向溢出
- 桌面端：1280px 宽下命盘字号放大
- 导出的 PDF：A4 横向，隐藏导航与按钮，保留命盘、四化、格局、大限

## 功能

- **排盘**：12 宫、十四主星、辅星煞星杂曜、庙旺利陷亮度、四化印章
- **真太阳时**：经度修正 + 均时差，界面会把「钟表时间 → 真太阳时 → 时辰」的每一步摊开显示
- **夏令时**：1986–1991 年出生者自动按 −1 小时校正
- **晚子时换日**：23:00 后出生自动归次日排盘，界面标注「按次日排盘」
- **大限**：点击任一步看该大限宫位与宫干四化，命盘对应宫同步高亮
- **格局**：基于《紫微斗数全书》的格局识别，点击查看释义、成立条件、破格条件与古籍出处
- **交互**：点宫位看详情（主星/吉煞/四化，可一键跳到对应解读）；点四化原地展开该星的星性、四化含义与应验；点大限切换该步宫位与宫干四化
- **选中色**：统一用橙色（#e2661f）内描边，不用外阴影或改边框宽度，避免布局跳动
- **解读**：13 个维度逐宫推演，每条论断标注所依星曜宫位，全部本地生成
- **城市库**：34 省级行政区、520 个市/区，标注经度

## 解读模块

13 维：命格总览、性格、感情、事业、财运、健康、兄弟、子女、迁移、人际、田宅、福德、父母。

**生成方式**：规则引擎，非 AI。数据源为四张知识表：

| 文件 | 内容 |
|---|---|
| `data-major-a.ts` / `data-major-b.ts` | 14 主星的本色、庙旺、落陷三层表述，及入宫专门论法 |
| `data-palace-extra.ts` | 14 主星 × 7 宫的补充表述（迁移/仆役/兄弟/子女/父母/田宅/福德） |
| `data-palace.ts` | 宫义、64 颗辅煞杂曜、地支脏腑、四化含义、五行局性格 |

**文风约束**（避免 AI 腔）：
- 每句必须能指到盘上某颗星、某宫或某四化，不写普适性套话
- 不解释生成方法，不写「换句话说」「这一段看的是」
- 正文不放免责声明，免责只在页面底部一行
- 建议只写宜与忌，不写励志话

**健康维度的双口径**：既按古法看疾厄宫主星，也按倪师《天纪》法——取全盘杀星最集中之宫，按其地支定脏腑（不按星曜五行推）。

**自检**：`npx tsx scan.ts` 扫 54 盘 × 13 维 = 702 条，检查无宜忌、总述过短、内部重复，当前均为 0。

## 排盘口径

- 换年：**正月初一**（非立春），与文墨天机、测测一致
- 闰月：**月中分界**（默认），可在引擎层切换归本月/下月
- 星曜亮度：按《紫微斗数全书》校订 24 处，覆盖 14 主星 + 6 辅星
- 四化：年干四化，庚干取「太阳武曲太阴天同」

## 正确性验证

用独立编写的教科书公式（不复用引擎代码）交叉核对 **864 盘，0 失败**：

- 命宫、身宫位置公式
- 紫微安星法（五行局 + 农历日）
- 十二宫逆序排布
- 十四主星齐备且不重复

复现：`npx tsx verify.ts`

## 开发

源码在 `/root/ziwei-web`（iSH 的 `/var/minis` 不支持软链，npm 装不了 esbuild）：

```bash
cd /root/ziwei-web
node build.mjs        # 产物输出到 /var/minis/workspace/ziwei-web
```

`src/lib/ziwei/` 是从 [Renhuai123/ziwei-doushu](https://github.com/Renhuai123/ziwei-doushu) 抽取的排盘内核（MIT），
删去了依赖 React / 数据库的 `history.ts`、`share.ts`、`famous.ts`、`heming-knowledge.ts`、`db-analysis.ts`。

### 构建时的两个坑

1. **`patterns.ts` 里有 `import 'server-only'`** → esbuild 用 `--alias:server-only=./src/empty.ts` 指向空模块。
2. **单文件内联必须用函数式替换**（`replace(re, () => text)`）。直接用字符串替换时，压缩后 JS 里的 `$&` 会被当成占位符，把整段内容破坏掉。

### 交互实现的两个坑

1. **`classList` 后期添加的样式在这个 WebView 里不触发重绘**。表现：元素类名已改、`getComputedStyle` 也返回新规则，但画面不变；连内联 `style` + `!important` 都不生效。解法：**状态变化一律走 `innerHTML` 重建节点**，不要靠后加类名。
2. **`<script>` 必须放在弹层 DOM 之后**。放在前面时脚本已执行完，`$('#sheet')` 拿到 `null`，事件绑定静默失败（关闭按钮点了没反应）。
3. 不再使用 CSS 入场动画（`animation`）。移动端实测出现卡在起始帧的情况：`transform` 停在 `translateY(100%)`、遮罩停在 `opacity: 0`，弹层等于不可见。

## 后续可扩展的三处接口

1. **引擎与界面分离**：`generateChart()` 是纯函数（生日进、JSON 出），同一份代码后续可直接跑在后端生成报告，盘与文案不会分叉。
2. **解读接口**：前端只需要一个 `interpret(chartJSON)`，现在是本地静态内容，将来整体换成 `POST /api/interpret` 时界面无需改动。
3. **报告导出**：当前「导出 PDF」调浏览器打印。要做成付费报告，只需后端把同样的 DOM 渲染成 PDF。
